# BMW M4 — 3D Scroll Experience

A scroll-driven, storytelling-style 3D advertisement page for the BMW M4, built with three.js. The camera orbits a 3D car model as you scroll, and the wheels spin with your scroll.

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Concept project. Not affiliated with BMW AG.
